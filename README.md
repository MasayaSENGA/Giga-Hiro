# ギガひろ

[ギガファイル便](https://gigafile.nu/)と[ギガワタス](https://giga-watasu.jp/)でファイルをアップロードする際に、保持期限（保存日数）を自動で指定した日数に設定するChrome拡張機能です。

## 概要

ギガファイル便・ギガワタスはアップロードのたびに保持期限（保存日数）を選択する必要がありますが、この拡張機能を入れておくとアップロード画面を開いた時点で自動的に希望の日数が選択された状態になります。

## 機能

- ポップアップから、サービスごとにデフォルトの日数を設定
  - ギガファイル便の保持期限: 3 / 5 / 7 / 14 / 30 / 60 / 100 日
  - ギガワタスの保存日数: 3 / 5 / 7 / 14 / 30 / 60 / 90 / 111 日
- ギガファイル便（`gigafile.nu` / `gigafile.jp`）
  - ページの読み込み時に、設定した保持期限を自動選択
  - 保持期限の選択肢が遅れて描画される場合に備え、最大10秒間DOMの変化を監視して自動選択
- ギガワタス（`giga-watasu.jp`）
  - アップロード画面（`/upload`）で、設定した保存日数のボタンを自動選択
  - ギガワタスは SPA のためページ遷移時にスクリプトが再読み込みされませんが、URL と DOM の変化を監視することで、画面遷移後も自動選択が動作
  - ポップアップで設定を保存すると、開いているアップロード画面にもリロードなしで反映
- 設定は `chrome.storage.sync` に保存され、ブラウザ間で同期

## インストール方法

### Chrome ウェブストアから

Chrome ウェブストアで公開しています。掲載ページで「Chrome に追加」を押すとインストールできます。

https://chromewebstore.google.com/detail/dfapbkmcfoglkkmabpdcggffhamgolkd

### 開発者モードで読み込む

このリポジトリは非公開です。開発中のコードを試すときは、手元のフォルダを読み込みます。

1. このリポジトリをクローンする
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択する

以前「ギガワタスひろ」を別途インストールしていた場合は、ギガひろに統合されたため `chrome://extensions` から削除してください（両方有効のままだと、ギガワタスで2つの拡張機能がそれぞれ日数を選択しようとします）。ギガワタスひろで設定していた保存日数は引き継がれないため、ギガひろのポップアップで「ギガワタスの保存日数」を設定し直してください。

## 使い方

1. ツールバーの拡張機能アイコンから「ギガひろの設定」ポップアップを開く
2. 「ギガファイル便の保持期限」「ギガワタスの保存日数」をそれぞれ選択する
3. 「設定を保存」をクリックする
4. ギガファイル便・ギガワタスのアップロード画面を開くと、設定した日数が自動的に選択される

設定を保存しない場合のデフォルト値は、ギガファイル便が **5日**、ギガワタスが **7日** です。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `settings.js` | ポップアップと各コンテンツスクリプトで共有する設定のデフォルト値 |
| `popup.html` / `popup.js` | 保持期限（保存日数）を設定するポップアップUI |
| `content-gigafile.js` | ギガファイル便のページで保持期限を自動選択するコンテンツスクリプト |
| `content-gigawatasu.js` | ギガワタスのページに常駐し、保存日数ボタンを自動選択するコンテンツスクリプト |
| `images/` | 拡張機能アイコン |

## 権限

- `storage`: 保持期限（保存日数）の設定を保存・同期するために使用します。
- コンテンツスクリプトは `gigafile.nu` / `gigafile.jp` / `giga-watasu.jp` のページでのみ動作します。

## プライバシーポリシー

https://privacy.love-live.jp/ で公開しています。全拡張機能で共通のポリシーで、このリポジトリとは別の、プライバシーポリシー用のリポジトリで管理しています。
