# ギガひろ

[ギガファイル便](https://gigafile.nu/)でファイルをアップロードする際に、保持期限を自動で指定した日数に設定するChrome拡張機能です。

## 概要

ギガファイル便はアップロードのたびに保持期限を選択する必要がありますが、この拡張機能を入れておくとページの読み込み時に自動で希望の保持期限が選択された状態になります。

## 機能

- ポップアップから保持期限（3 / 5 / 7 / 14 / 30 / 60 / 100 日）を設定
- `gigafile.nu` および `gigafile.jp` へのアクセス時、設定した保持期限を自動選択
- 保持期限の選択肢が遅れて描画される場合に備え、最大10秒間DOMの変化を監視して自動選択
- 設定は `chrome.storage.sync` に保存され、ブラウザ間で同期

## インストール方法

1. このリポジトリをダウンロードまたはクローンする
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択する

## 使い方

1. ツールバーの拡張機能アイコンから「ギガひろの設定」ポップアップを開く
2. デフォルトの保持期限を選択する
3. 「設定を保存」をクリックする
4. [ギガファイル便](https://gigafile.nu/)にアクセスすると、設定した保持期限が自動的に選択される

設定を保存しない場合、保持期限のデフォルト値は **5日** です。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `popup.html` / `popup.js` | 保持期限を設定するポップアップUI |
| `content.js` | ギガファイル便のページで保持期限を自動選択するコンテンツスクリプト |
| `images/` | 拡張機能アイコン |

## 権限

- `storage`: 保持期限の設定を保存・同期するために使用します。

## バージョン

現在のバージョン: 3.2（`manifest.json` を参照）
